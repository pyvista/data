Viewpoint Animation Engineering / Viewpoint DataLabs dataset terms

Source: the header of `Data/cow.obj` (the same bytes as
`Data/Viewpoint/cow.obj`), the only file under this identifier that carries
any text; `cow.g`, `cow.vtp`, `cowHead.vtp`, `iflamigm.3ds` and
`iflamingo.3ds` carry none. VTKData commit
e8098138988b98aac743429577f669454f57f7e8 (Jim Miller, 20 August 2001,
"Files distributed with permission from Viewpoint") brought `cow.g`,
`cow.obj` and `iflamigm.3ds` into VTK's data with a README beside them.
This is not an SPDX-listed licence; the wording it is based on is quoted
here.

The README that commit added beside the files, which this repository no
longer carries, read in full:

    Datasets provided by Viewpoint DataLabs International, Inc.
    625 South State Street
    Orem, Utah 84058
    1 801 229 3000

    http://www.viewpoint.com

    These folks have a massive collection of high quality datasets for sale.
    They also host the avalon repository of free datasets.

What this means for a downstream user:

  - The header authorizes Sun Microsystems to distribute the datasets, and
    VTK's commit message records that Kitware distributes them with
    Viewpoint's permission. It does not grant redistribution to everyone.
  - It grants unlimited use in existing or modified form.
  - The geometry may not be resold in existing or modified form, which is
    why `commercial_use = false`. A product that merely uses the model is
    not addressed either way.
  - No credit is asked for. The header names Viewpoint Animation
    Engineering, Orem, Utah, as the source, and the Avalon archive as the
    route by which Sun contributed the file.
